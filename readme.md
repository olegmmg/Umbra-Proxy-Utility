## О программе

**Umbra** — десктопный клиент для работы с прокси-подписками на Windows. Построен на Rust и встроенном Xray-core, поддерживает VLESS, VMess, Trojan, Shadowsocks и Hysteria2, а также режимы TUN и системного прокси.

Программа не является форком какого-либо открытого проекта — это самостоятельная разработка. Исходный код не распространяется.

## Возможности

### Протоколы
- **VLESS** (TCP, WS, gRPC, XHTTP, H2)
- **VMess**
- **Trojan**
- **Shadowsocks** (SIP002)
- Поддержка **Reality**, **TLS**, **XTLS-Vision** (flow `xtls-rprx-vision`)

### Подключение
- **TUN-режим** через Wintun — весь системный трафик идёт через туннель без настройки прокси в браузере
- **Системный прокси** — автоматическое включение/отключение HTTP-прокси в Windows
- Автозапрос прав администратора при старте, если включён TUN
- Автоматическое определение архитектуры (`x64` / `x86`)

### Подписки
- Загрузка по URL с User-Agent **`happ/4.3.0`** — совместимость с популярными провайдерами
- Поддержка кастомного User-Agent для каждой подписки отдельно
- Отображение остатка трафика, даты истечения, времени последнего обновления
- Сворачивание и закрепление подписок
- Автообновление с настраиваемым интервалом
- Копирование URL в один клик

### Пинг
Три метода, каждый для своей задачи:

| Метод | Что измеряет | Когда работает |
|---|---|---|
| **ICMP** | Классический `ping.exe`, RTT до сервера | Всегда |
| **TCP** | Handshake к порту сервера | Всегда, кроме Hysteria2 |
| **Via Proxy** | Полный RTT через туннель до `gstatic.com/generate_204` | Всегда — при отсутствии подключения Umbra поднимает временный Xray, пингует и гасит его |

- **Game mode** — прогревает туннель 2.5 секунды перед замером, чтобы цифры были реалистичными для игр
- Настраиваемый таймаут (1–5 с), число попыток (1–5), параллельных запросов (1–32)
- Массовый пинг всей подписки через пул воркеров — не забивает систему при 2000+ серверах

### Безопасность и хранение
- Все настройки и подписки хранятся в `%APPDATA%\Umbra\config.dat`
- Файл зашифрован через **Windows DPAPI** — расшифровать может только текущий пользователь на этой машине
- Пароли, ключи Reality, UUID и URL подписок не лежат открытым текстом

### Импорт
- Подписки по URL
- **JSON-конфиги Xray** — парсинг `outbounds`, поддержка VLESS, VMess, Trojan, Shadowsocks, Hysteria2

## Установка

### Portable

1. Скачайте `Umbra-0.1.12-windows-portable.zip` из [релизов](../../releases/latest)
2. Распакуйте в любую папку (например, `C:\Umbra\`)
3. Запустите `Umbra.exe`
